Anyone can make a token and name it NVDA. copy-guard looks at which token moved, who signed for it and what the person it acts for allows. Then it writes down what it did and why, in plain sentences.

What it decided, one card per move

Each card starts with a score, the number of checks that passed, and a mark for each group of checks. A red flag is a check that did not pass. It describes the move and says nothing about any person. Each card is built from fixed sentences filled with the values the rules read. No language model writes or decides anything, so the same inputs always give the same card. The card is part of the record whose hash is onchain.

The practice ledger

Two books walk through the same moves in the order they happened. copy-guard opens what its rules, its mandate and the user's limits allow. Ticker copy is a baseline I defined: it opens a position whenever a token with a stock ticker arrives in the wallet.

Practice (paper) positions. This is not a forecast and not a track record. A position in a token that is not the issuer's is valued only where the price of its own pool could be read from public logs. Otherwise it is listed as not measured and left out of every sum. Nothing is assumed to be worth zero. A pool value compares the pool's last swap with the swap the wallet bought in. It leaves out the move of the pool's other asset in USD, and it does not say that a position of that size could have been sold there.

Chainlink CRE: a compliance check before the agent acts

Three CRE workflows sit around the decision. They are run with cre workflow simulate. Nothing is deployed to a DON, and a simulated write goes through CRE's simulation forwarder, which accepts reports from anyone. The events fix a hash and a time. They are not a DON attestation, which is why the recheck at the end of this page exists.

RYO-CHAN: the same care, for stock tokens

RYO-CHAN protects investors with an anti-rug scanner. copy-guard does a neighbouring job for stock tokens: before anything copies a move, it says in everyday language which token moved and whether it is the issuer's.

The bounty textOn this page
“record the practice trades they would make”The practice ledger: every decision, the position it opened or did not open, with entry, size and exit.
“show cause and effect”Every card: what happened, why, and the action that follows.
“preserve a repeatable reasoning trail”No language model. The same inputs and the same limits give the same trail, and the recheck repeats it with separate code.
“transparent signal rules and user-defined risk limits”Fixed rules, and the limits the user wrote.
“Explain selected and rejected candidates”Declined moves stay in the ledger, each with its reasons.

One sentence, two values. A person who says “put at most $50 on one stock and stop the loss at 15%” changes two lines of limits.json: "full_usd": "50.00" and "stop_loss_pct": "15". The file is edited by hand, and there is no parser for the sentence. Every later decision names the new file by hash, and the mandate has to be signed again, because new limits need the principal's consent.

What this does not claim

  • Practice (paper) trades only. No real trade was placed, and nothing here says that copying any wallet makes money.
  • The ledger compares two policies on past public moves. It is not a forecast, not a track record and not advice.
  • No token and no person is called a scam here. The record says which contract moved and that its address is not the one the issuer listed.
  • The principal is an address. Nothing here ties it to a legal identity.
  • The walk is a replay. Each wallet's record was read once, after the moves, so the rules judge a wallet with what is known now.
  • Feed values arrive a few times a day. An entry price can be hours older than the move, within the age limit the user set.
  • No customer yet. The one payment so far is my own test.
  • This is not legal advice and not investment advice. vet402 reports what public chain data shows and is not affiliated with Robinhood, Chainlink, RYO or any token issuer.

A ticker is a string that anyone can reuse. This page says which contract moved, who signed for it and who allowed the agent to act. Don't take my word for it. Run it.
